# transactions_analytics

Generated by **Developer Agent** using official dbt-labs agent skills.

## Requirement

Generate a dbt incremental model called fact_transactions that merges on transaction_id, joins with dim_account and dim_currency, uses liquid clustering on transaction_date, account_id, and currency_code, and includes audit columns (_loaded_at, _invocation_id, _dbt_model). Include staging models for transactions, accounts, and currencies, dimension models dim_account and dim_currency, source definitions with freshness checks, and full test coverage including relationships tests on foreign keys.

## Quick Start

```bash
# Install dependencies
dbt deps

# Run seeds
dbt seed

# Full refresh (first time)
dbt build --full-refresh

# Incremental run
dbt build
```
